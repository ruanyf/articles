# 科技爱好者周刊（第 438 期）

## 工具

1、[DOMPurify](https://github.com/cure53/DOMPurify)

一个 JS 模块，用来清理 HTML 代码，防止 XSS 攻击。

1、[Popply](https://github.com/JhojanGgarcia/PopplyLibrary)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070403.webp)

一个工具提示（tooltip）的 CSS 库，收集了各种动画效果的 CSS 片段代码。


1、[Posting](https://github.com/darrenburns/posting)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070711.webp)

一个在终端使用的 HTTP 客户端，用来测试 HTTP 请求，功能与 Postman 类似。

1、[impala](https://github.com/pythops/impala)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070810.webp)

Linux 终端里面的 WIFI 管理器。

1、[Tegon](https://github.com/tegonhq/tegon)

![](https://cdn.beekka.com/blogimg/asset/202407/bg2024070905.webp)

一个开源的任务管理系统，Jira 的替代品。



1、[Rybbit](https://github.com/rybbit-io/rybbit)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025050804.webp)

网站访客的开源统计工具，Google Analytics 的替代品。

1、[VeraCrypt](https://github.com/veracrypt/VeraCrypt)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025050408.webp)

功能强大的数据加密软件，可以加密整个磁盘，支持各种桌面系统，参见[介绍文章](https://www.xda-developers.com/started-using-tool-encrypt-files/)。

3、[CodeCafé](https://github.com/mrktsm/codecafe)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025050601.webp)

基于浏览器的开源 Web 代码编辑器，可以实时协同编程。

1、[gotui](https://github.com/metaspartan/gotui)

![](https://cdn.beekka.com/blogimg/asset/202512/bg2025121201.webp)

一个构建终端界面的 Go 库，提供各种小部件。


1、[@storyteller-platform/epub](https://gitlab.com/storyteller-platform/storyteller/-/tree/main/libraries/epub)

一个处理 Epub 电子书文件的 JS 库，参考[介绍文章](https://storyteller-platform.dev/blog/20261001_epub_v1/)。

## 资源

1、[公园一分钟](https://oneminutepark.tv/?minute=10:20)

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026093009.webp)

这个网站让世界各地的用户，上传在公园拍摄的1分钟视频，并且注明拍摄时间。

它的目标是让每天的1440分钟都有对应的1440个公园视频。我没仔细了解，它怎么解决时差问题。

1、[CSS Bed](https://www.cssbed.com/)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026100511.webp)

该网站可以在线查看各种“无类 CSS”框架（只对 HTML 标签设置规则）的渲染效果。

1、[大菱形二十面体](https://www.software3d.com/MillersMonster.php)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026100514.webp)

这个网页介绍如何用42张 A4 纸，折出这个124面的多面体。

1、[全球太阳能地图](https://globalsolaratlas.info/map)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026100802.webp)

这个网站提供全球太阳光日照强度的地图，可以查看任意地点的日照数据。

1、[Jujutsu 用法入门](https://arialdo.codeberg.page/ju-ju-tsu/preface/preface.html)

![](https://cdn.beekka.com/blogimg/asset/202609/bg2026093010.webp)

Jujutsu 是一个新兴的版本管理系统，有自己的一套概念。这本免费的英文电子书面向初学者，解释它的概念，以及基本的用法。

1、[Totally Useless Websites](https://www.totallyuselesswebsites.com)

![](https://cdn.beekka.com/blogimg/asset/202505/bg2025051206.webp)

该网站专门收集完全无用无意义的网站。
