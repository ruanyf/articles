# 科技爱好者周刊（第 433 期）

## 工具

1、[ScreenPlay](https://screen-play.app/)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082203.webp)

一款适用于 Windows 和 OSX 的开源动态壁纸应用。

1、[Plasmo](https://github.com/PlasmoHQ/plasmo)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082205.webp)

一个开发 Chrome 浏览器插件的框架。

1、[Mox](https://www.xmox.nl/)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025030502.webp)

一个 Email 服务器，带有完整功能：接收、发送和 Web 界面。

3、[grist](https://github.com/gristlabs/grist-core)

![](https://cdn.beekka.com/blogimg/asset/202503/bg2025030507.webp)

基于网页的类 Excel 电子表格应用，采用服务器-客户端结构。

3、[Terminus](https://github.com/beclab/Terminus)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082508.webp)

可以自搭建的家庭云，集成了很多内网使用的云服务。

4、[ChartDB](https://github.com/chartdb/chartdb)

![](https://cdn.beekka.com/blogimg/asset/202408/bg2024082604.webp)

一个数据库可视化工具，它会提取你的数据库的模式（schema），将其可视化显示。

1、[Modern Speck](https://github.com/vangelov/modern-speck)

![](https://cdn.beekka.com/blogimg/asset/202602/bg2026022806.webp)

一个网页应用，在浏览器里面 3D 渲染分子结构。

2、[manim-web](https://github.com/maloyan/manim-web)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026030102.webp)

这个工具将 [Manim](https://github.com/3b1b/manim)（数学动画工具）搬到了网页，可以在网页上生成数学动画。

3、[Qman](https://github.com/plp13/qman)

![](https://cdn.beekka.com/blogimg/asset/202603/bg2026030204.webp)

一个命令行工具，终端的 Man（手册页）阅读器，方便浏览和查找手册。

1、[SnapCode](https://reportmill.com/SnapCode/)

![](https://cdn.beekka.com/blogimg/asset/202402/bg2024020807.webp)

浏览器里的 Java IDE。

## 图片

1、[苏联的航天导航仪](http://www.righto.com/2023/01/inside-globus-ink-mechanical-navigation.html)

苏联发展航天的过程中，开发了很多自己的仪器，其中最奇特的大概就是导航仪。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120503.webp)

那个年代还没有全球导航系统 GPS。仪器内部是一个地球仪，用来指示飞船当前的位置。

它非常复杂，不是通过电子元件，而是通过机械装置来显示航天器的位置。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120504.webp)

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120505.webp)

地球仪上还贴着编号为1到8的圆圈，表示与航天器通信的地面站点位置，使宇航员能够确定当前下方是哪一个地面站。

![](https://cdn.beekka.com/blogimg/asset/202312/bg2023120506.webp)

地球仪被齿轮带动，会跟着航天器同步旋转。
