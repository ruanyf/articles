# TRAE 终于下决心转型，推出最容易上手的个人开发助理

## 一、引言

今天，我看到字节旗下的 AI 编程工具 [TRAE](https://www.trae.cn/)，添加了个人开发助理”TRAE 宝“（英文名 TRAE Bot），是**这个工具诞生以来最简单的使用入口**。

建议大家看一下，这个功能非常有用，大大简化了 AI 开发。哪怕你不是开发者，现在也能很简单地做出软件了。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102901.webp)

一直有人问我，为什么你要用 TRAE，有那么多的 AI 编程工具呢？

有几点理由，值得你把它留在自己的工具箱里。

（1）它送积分很慷慨，有积分就可以免费使用。当你没有其他 AI 订阅或额度用光时，它简直是救星。

（2）它提供桌面端、手机端、云端和 Web 端。遇到各种需要 AI 编程的使用情景，它基本都原生支持。

（3）它同时提供 Agent 模式和 IDE 模式（或 VS Code 和 Jetbrains 插件）。当你想切换到传统 IDE 时，非常方便。

但是，它有一个问题，影响了推广：它太像程序员工具了！

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102902.webp)

上图是它的 IDE 界面，也是长期以来的主界面。太专业了，不像其他 AI 编程工具那样简洁，程序员在里面调用 AI 编码，都会觉得有点繁琐，更别说吸引非程序员用户了。

## 二、TRAE 宝的诞生

TRAE 也意识到这个问题，一直在设法改变，简化 AI 编码的使用。

于是，在 IDE 模式之外，又加入了 Agent 模式，**从代码导向转为任务导向**。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102810.webp)

上图就是 Agent 模式，界面大大简化，向其他 AI 工具靠拢了。用户只需在对话框发布任务，后面就由 AI 来完成编码。今年年初，AI 个人助理走红，AI Agent 类软件成为一种潮流。TRAE 团队也意识到，这应该是未来的趋势。

现在，TRAE 决定进一步推进这种转型，推出了更容易上手的“TRAE 宝”。

**“TRAE 宝”是 TRAE 目前最方便的使用入口**。下面是它的几个设计要点，大家看看是不是完全从方便用户使用出发。

（1）所有操作都是对话式，只需描述项目，其他都帮你搞定。

（2）所有对话、操作和 AI 产物，都集中在一个页面管理，也就是入口页。整个功能基本只有这一个页面。

（3）在这个页面上，多项目并行开发。按时间顺序，显示不同项目的消息，跟它们对话，不用切换页面。

（4）所有项目构成一个大的上下文，即跨项目记忆。对于跨项目开发和长期开发，非常有用，上下文不用手动搬运，“TRAE 宝”有长期记忆。

（5）绑定飞书微信，可以在手机聊天软件里对话使用。

总之，它简直就是傻瓜式设计，下面我来演示一下，它具体长什么样。

## 三、使用方法

“TRAE 宝”这个功能，位于 Agent 模式里面，可以先在右上角切换到 Agent 模式。

Agent 模式左侧菜单栏的第二个选项，就是“TRAE 宝”。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102811.webp)

上面菜单的第一个选项“新建任务”，就是 Agent 模式的主界面，前文已经有截图。

Agent 模式和“TRAE 宝”，这两个入口的功能其实是相似的，都能发布 AI 编码任务，进行开发。

它们的不同之处在于，Agent 模式（也就是菜单里的“新建任务”）只能新建单个任务，如果要新建第二个任务，就要再点击一下，再开一个新页面。

“TRAE 宝”则始终是单一页面，所有任务都在该页面完成。你再点击菜单，打开的也是这个页面。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102812.webp)

上图就是“TRAE 宝”的样子，除了菜单栏，页面分成左右两个部分。左侧是对话页，用来跟系统进行对话交互，右侧是工作台，展示所有项目的列表和 AI 生成的所有产物。

另外，“TRAE 宝”分成两个级别：“全局助理”和“项目助理”，通过页面上方的图标区分（下图）。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102813.webp)

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102814.webp)

在项目页点击图标，打开的就是项目助理。

## 四、并行开发

“TRAE 宝”最有用的一个功能，就是不同任务的并行开发。

我来演示一下，先让“TRAE 宝”帮我开发一个网页游戏“俄罗斯方块”。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102817.webp)

大家注意看上图，对话下方自动生成当前任务的名称，以及一个旋转的圆圈，表示“正在生成中”。这里是可以点击的，会打开当前任务的页面，查看具体进展。

我们先不管这个任务，接着发布了第二个任务：生成一个网页三消游戏。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102818.webp)

上图可以看到，两个任务在并行执行，各自的进展可以在自己的任务页面查看。

以“网页三消游戏”为例，点击它的旋转小圆圈，进入它独立的任务页面，默认在窗口右半边打开。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102819.webp)

上图中，上方的 Tab 栏用来切换不同的任务页面。

Tab 栏的第一个页面，总是工作台页面，会显示“最近任务”的汇总，以及所有任务的”工作产物“。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102820.webp)

这个工作台，用来统一管理并行的多任务和各种产物，方便随时切换查看。

## 五、跨项目记忆

“TRAE 宝”还有一个很强的能力，就是会形成“跨项目记忆”。

因为所有项目都在同一个窗口完成，它可以把这些项目做成同一个上下文。这样的好处就是，在 A 项目里面可以带入 B 项目（比如要求 AI 借鉴 B 项目的代码），以及生成所有项目的统计和分析。

此外，“跨项目记忆”也有利于记住用户的个人信息和偏好。如果长时间使用，模型对用户的了解会越来越多，就能做出一些定制化和个性化的东西。

举例来说，我主要使用 JavaScript，而不是 TypeScirpt，后端偏好使用 Node.js，前端偏好原生 HTML、CSS 和 JavaScript，不喜欢引入太多依赖，日期统一使用 YYYY-MM-DD 格式。长期使用后，它记住了这些，我再跟它说“给网站增加一个文章搜索功能”，它就自己知道该用什么技术栈实现。

绑定以后，在手机的飞书和微信里，就能跟 TRAE 对话，远程发起任务，所有动态都会在各种客户端实时同步。

下图是电脑端的绑定窗口。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102815.webp)

绑定以后，下图就是手机飞书跟 TRAE 的对话界面。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102816.webp)

你可以在手机上发布任务，让本地的 TRAE 来跑。

## 七、总结

我的想法前面已经说了，“TRAE 宝”作为 AI 开发的个人助理，可以作为每一个 TRAE 用户的主入口。

首先，对于专业程序员，它绑定了很多功能，比如自动调度子任务、并行推进、联调与汇总等等，方便了多任务和大项目的开发，让开发者只需看汇总报告、做判断，减轻了手动操作的麻烦。

其次，对于普通用户，它不仅让你可以轻松上手软件开发，还相当于为你配置了一个程序员助理。你只要轻松当老板，具体交代给这个助理去办，等着验收和判断就好。

## 简介

TRAE 个人助理可以跨项目理解历史上下文，也可以在单个项目里拆解、并行、统筹多个任务。

- 核心场景：开启新任务时不再从零解释；复杂项目推进时，不再自己拆任务、切会话、盯进度、拼结果。
- 内容目标：通过真实项目实测，让用户看到从“会做一条任务”到“持续理解并推进开发工作”的变化。体会到任务交给个人助理，自己「当老板」的爽感与轻松感。
