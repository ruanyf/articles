# 传说中最强开源模型 Kimi K3.1 Pro 简单实测，是否名副其实

## 一、引言

一周前，我在海外社媒平台看到一个热门帖子。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102601.webp)

它统计了几家主要 AI 厂商的上一个模型发布至今的天数，言下之意不言而喻。

最近两个月，海外模型频繁发布、纷纷霸榜，而国产模型却相对沉闷，几乎没有重大发布。

一时之间，唱衰的言论甚嚣尘上，比如“只要离开了蒸馏，就发不了新版本”，上面这个帖子就是一个例子。

下面还有人附言：“卖这么贵，也不过如此”，讽刺 Kimi K3 的价格接近美国的闭源模型。

就是在这种质疑中，Kimi 上周末终于推出了新模型 [K3.1 Pro](https://platform.kimi.com/docs/guide/kimi-k3-1-pro-quickstart)，作为回应。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102602.webp)

我之前就知道 Kimi 要发新模型，但是仔细阅读发布公告，还是感到震惊，没想到这一版的提升幅度这么大。

Kimi 上一个模型 K3 其实已经很强了，是参数规模最大的开源模型，达到了 3T 级别（实际参数规模 2.8T，权重文件大小 1.56TB）。谁能想到，K3.1 Pro 居然又把表现提升了一个档次。

根据第三方 [Artificial Analysis](https://artificialanalysis.ai/models/kimi-k3-1-pro) 评测报告，K3.1 Pro 的 AA 指数46分，排名所有模型的第九位，落后于 Opus 5.5（58分） 和 GPT-6-Astra（57分）。

![](https://cdn.beekka.com/blogimg/asset/202610/bg2026102808.webp)

大家可能不知道，Artificial Analysis 本周更换了测试题目，导致国产模型的排名都有较大的下降，就像我上次看的时候 K3.1 Pro 还排名第四，今天就变成第九了。

但即使如此，它还是在所有开源模型中排名第一，而且比后面的 Qwen 3.8 Max（34分）、DeepSeek V4.1 Flash 1017（32分）、GLM-5.3（32分）得分高出不少。它真有这么强吗？

## 二、K3.1 Pro 的表现

先看一下，K3.1 Pro 这次提升在哪里。

跟据发布公告，它也是 3T 参数级别，依然属于最大的开源模型，相比 K3 提升显著。

**（1）Agent 和 Code 能力**。它在衡量命令行执行复杂任务能力的 Terminal-Bench 4.0 跑出 65.7%，超过 GPT-6 Astra（58.2%），只略低于 Claude Opus 5.5（66.4%）。

**（2）3D 能力和工业建模能力**。它可以直接在 Unreal、Unity 和 Godot 里做全项目级别的游戏工程，以及在 Blender 和 CAD 里包揽建资产、搭场景、动画渲染全流程。在衡量计算机辅助设计能力的 BenchCAD，它拿了92.7%的高分，基本追平了 Opus 5.5（96.2%）和 GPT-6 Astra（95.9%）。

**（3）金融和商业分析能力**。它在衡量企业级复杂财务数据分析能力的 OfficeQA Pro v2 得分64.4，是所有模型的最佳成绩，其中的经营管理决策能力足足是 K3 的4.2倍。 

以上这些还不是最亮眼的，提升能力的同时，它的幻觉率降了65%，而**运行速度快于 K3，但计费比 K3 便宜了三分之一**。

## 六、后训练的威力

经过这些测试，说实话，我觉得，K3.1 Pro 总体表现跟 Claude 系列的最新模型（比如 Opus 5.5）还是有一点差距，但在个别领域完全可以一较高下，称得上是目前最好的开源模型之一。

如果要做重大的软件项目，我想大多数人还是会优先考虑 Claude 模型。但是，平时的日常项目使用 K3.1 Pro 应该是毫无问题的。希望 Kimi 在编程领域继续进步，尤其加强对小众编程语言的支持，有一天能跟最好的闭源模型并驾齐驱。

最后，在[发布公告](https://mp.weixin.qq.com/s/Q6Z-skAUH_na9g37VWbHew?from=groupmessage&scene=1&subscene=10000&clicktime=1792775934&enterid=1792775934&sessionid=0&ascene=1&fasttmpl_type=0&fasttmpl_fullversion=8490647-zh_CN-zip&fasttmpl_flag=0&realreporttime=1792775934851)这样说：

> “Kimi K3.1 Pro 是 Kimi K3 的后训练版本，后训练算力大幅增加。”

所谓“后训练”，说得通俗一点，就是对原始模型延长训练时间，不改变训练材料和参数规模，只对训练过程进行调整和优化。

> “我们优化了技术栈的每一层，包括 RL 框架、长上下文推理、训练效率、沙箱基础设施、调度系统，以及用于环境质量检查的共享平台等，确保每一份新增的 RL 算力都能转化为稳定、高效的回报。最终，Kimi K3.1 Pro 模型在所有领域都获得了大规模 RL 带来的全面提升。”

只对原始模型再加工，就能取得如此大的进步，联想到 GLM 5.3 也是对 GLM 5.2 的后训练，并且也是进步显著，我感到后训练可能要成为以后新模型发布的一种趋势。

毕竟训练材料和参数规模到达一定程度后，很难再有大幅提升，还是要从训练过程和方法上挖掘潜力。

未来，预训练和后训练会变得同等重要。预训练将训练材料喂给模型，确定模型的“知识底座”，可以说决定了能力的下限；后训练不断细化和优化训练方法，将粗糙模型变成专家模型，探索能力的上限。

不过国内很多模型厂商其实都很难端出大尺寸的模型，何况还要做如此大规模的后训练，月之暗面确实是一个孤独的登月者，在资源有限的情况下，挑战别人做不到的技术。现在新模型发布后，感觉也是资源紧缺，在使用的过程中也频繁遇到了429情况。

## 预训练打底，后训练改命：Kimi K3.1 Pro 进化背后的关键

## 一、国产模型的反击

最近两个月，国产模型相对沉默，海外模型异常活跃，不仅密集发布，而且频频霸榜。Kimi K3.1 Pro 的发布打破了这种沉闷。

它用自己出色的性能，回应外界的质疑，比如“不能蒸馏，中国模型就完了”。它的 AA 评分高达 55，在所有模型中排名第4，只低于 Opus 5.5 和 Sonnet 5.5，位于开源模型的榜首。

## 二、后训练的神奇表现

K3.1 Pro 最值得关注的地方是，它并非一个全新的模型，而是来自模型 K3 的后训练。

> “Kimi K3.1 Pro 是 Kimi K3 的后训练版本，后训练算力大幅增加。”（[模型的发布公告](https://mp.weixin.qq.com/s/Q6Z-skAUH_na9g37VWbHew?from=groupmessage&scene=1&subscene=10000&clicktime=1792775934&enterid=1792775934&sessionid=0&ascene=1&fasttmpl_type=0&fasttmpl_fullversion=8490647-zh_CN-zip&fasttmpl_flag=0&realreporttime=1792775934851)）

[什么是后训练？本质就是训练时间的延长，以及训练过程的调整和优化。]

K3.1 Pro 来自 K3 的后训练，模型的各方面表现都有了神奇的提高。

（1）Agent 和编码能力：Terminal-Bench 4.0 跑出 65.7%，压过 GPT-6 Astra（58.2%），只比 Claude Opus 5.5（66.4%）差一点。

（2）3D 和工业建模能力。可以直接在 Unreal、Unity 和 Godot 里做全项目级别的游戏工程。直接在 Blender 和 CAD 里做参数化建模，从建资产、搭场景到动画渲染都能包揽。BenchCAD 拿了 92.7% 的高分，基本追平了 Opus 5.5（96.2%）和 GPT-6 Astra（95.9%）。

（3）金融和商业分析。幻觉率降了 65%，OfficeQA Pro v2 刷到了 SOTA（64.4），模拟业务运营表现是 K3 的 4.2 倍。

除了上面的能力提升，更重要的是，它的运行速度比 K3 提高了，而且还有 Highspeed 版，比普通版快 2-3 倍。而它的 API 计费标准反而比 K3 降低了大约三分之一。

## 三、后训练改进模型的原因

训练数据和参数数量都没变，只是进行了后训练，为什么会发生这样大的改变？

官方发布声明的解释：

> “为了支撑数百个下游领域的大规模联合训练，我们优化了技术栈的每一层，包括 RL（强化学习）框架、长上下文推理、训练效率、沙箱基础设施、调度系统，以及用于环境质量检查的共享平台等，确保每一份新增的 RL 算力都能转化为稳定、高效的回报。
>
> 最终，Kimi K3.1 Pro 模型在所有领域都获得了大规模 RL 带来的全面提升。”

K3.1 Pro 转向后训练，我认为首要原因是 K3 的参数规模已经达到了 3T 级别，是所有开源模型中最大的。K3/K3.1 的参数量已经达到了 3T 级别，进一步提升参数的意义不大了，不如转向参数效果的优化。

具体来说，后训练有下面几种做法，可以改造模型。

（1）加大后训练算力（Post-training Compute）。

以前，大家觉得，只有预训练才需要大规模算力，因为根据 Scaling Law（规模法则），堆算力、堆数据，堆的规模越大，效果越好。

现在的认识是，后训练同样需要堆算力，以便进行大规模强化学习（Large-scale RL）。Kimi 官方介绍 K3.1 Pro 后训练的第一句话就是“后训练算力大幅增加”，让模型在没有重跑底层预训练的情况下，实现了综合能力的大幅增长。

（2）奖励建模（Reward Modeling）与环境反馈。

后训练通过精准设计的奖励和反馈，让 AI 在沙盒环境中不断尝试、试错、自我纠偏，从而提升表现。

以 K3.1 Pro 为例，官方举了一个人类行走动力学仿真器的例子。使用奖励机制，“持续分析实验结果、定位问题并迭代优化行走控制器，推动仿真人体从最初几步内便倒地，进步到能够交替迈步、连续行走 11.2 秒。”

（3）多领域联合的强化学习（Joint RL across Domains）。

后训练从单一领域（如数学题或简单代码）的强化学习，扩展到数百个不同领域（代码、3D 建模、金融分析、安全审计等）同时做大规模联合强化学习，增强模型对于跨领域复杂问题的处理表现。

这需要算法改进，以及工程堆栈和基础设施的整体优化（比如调度、沙盒隔离等）。Kimi 的介绍是“为了支撑数百个下游领域的大规模联合训练，我们优化了**技术栈的每一层**，包括 RL 框架、长上下文推理、训练效率、沙箱基础设施、调度系统，以及用于环境质量检查的共享平台等。”

（4）幻觉抑制与事实验证。

预训练无法根本解决幻觉，必须依靠后训练阶段的事实性强化学习（Factuality RL）和检索增强/交叉验证训练。

“后训练让 K3.1 Pro 的幻觉率从 K3 的 23.4% 直降至 8.3%，至少包含一个事实错误的回答比例下降了超一半。” 对于那些需要严格事实支持的领域（如金融/财报分析），后训练起到了决定性作用。

（5）数据修正与安全保证。

后训练可以精准修剪与管控数据，并能定向清洗与过滤数据，阻止模型在高风险领域滥用能力（如网络攻击）。

“我们发现若在中期训练和强化学习阶段均不移除相关数据，下游网络攻防能力将大幅增强。在准备发布 K3.1 Pro 开放权重版本时，我们从两个训练阶段均识别并移除了网络攻防相关数据，同时保留了保障模型实用性所需的通用编程任务。”

## 五、总结：预训练与后训练

后训练（Post-training）正变得与预训练（Pre-training）同等重要。

预训练的目的是获得“知识底座”（通识能力），方法是喂给 AI 海量的训练材料。后训练的目的则是调教模型，把预训练得到的粗糙模型变成遵从指令、逻辑严密、懂规矩且能善于解决实际问题的专家，方法是通过对齐、强化学习和指令微调的训练。

在 K3.1 Pro 之前， GLM 5.3 也是 GLM 5.2 的后训练模型，效果非常好。

后训练将成为以后开发新模型的一种趋势。可以这样说，预训练决定了模型的下限，后训练决定了模型的上限。
